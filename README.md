# SwiftlyKitCLI

Standalone command-line interface for
[SwiftlyKit](https://github.com/mottzi/SwiftlyKit).

The package uses the exact tagged SwiftlyKit `0.3.1` dependency by default.
During local development, select the sibling checkout instead:

```console
SWIFTLYKIT_USE_LOCAL_DEPENDENCY=1 swift build
```

The command interface has not been implemented yet.
